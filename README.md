# Fleet Management Backend API

A scalable backend system for the Cargo Logistics Platform built to manage cargo transportation, fleet coordination, shipment tracking, and logistics operations. The backend provides secure RESTful APIs for handling users, vehicles, deliveries, assignments, and system management.

## Project Goal

The goal of this backend system is to provide a reliable and efficient server-side infrastructure for managing logistics and fleet operations. It automates shipment workflows, vehicle assignments, delivery tracking, and user management while ensuring scalability, security, and maintainability.

## Features

- RESTful API architecture
- Authentication and authorization
- Role-based access control
- Shipment and delivery management
- Fleet and vehicle management
- Driver and transporter coordination
- Real-time delivery status updates
- Admin and broker management
- Secure database integration

## User Roles

- Customer/Shipper
- Transporter/Driver
- Broker/Dispatcher
- Administrator

## Tech Stack

- Node.js
- Express.js / NestJS
- PostgreSQL / MongoDB
- JWT Authentication
- REST API
- Docker (optional)
